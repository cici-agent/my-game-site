# 霍格沃茨 · 七册同行
## 多人 3D RPG 首版

玩家从国王十字车站出发，以第三人称操控学生，穿过七册主线，终点是霍格沃茨大战后的清晨。每次首领胜利都单独结算给参与战斗的玩家。朋友可以同时打赢同一场战斗，分别选择何时走向下一地点。

### 可玩的路线

| 地点 | 玩家在场景中做什么 | 核心挑战 |
|---|---|---|
| 入学与万圣节 | 车站选角，观看录取信与列车序章，穿墙登车，跟海格走到码头、乘船、上岸，在教室托起羽毛，去回廊训练 | 巨怪挥棒后引开目标，用漂浮咒举起木棒 |
| 第一册 · 魔法石 | 穿过营地，走进活板门下，举杖照亮镜片、辨认真身 | 奇洛与魔镜，照镜后抓住真身的破绽 |
| 第二册 · 密室 | 在蛇柱间拾起碎镜，携带碎片、修好镜面 | 引开蛇怪，闪过扑击，修复反光镜 |
| 第三册 · 阿兹卡班的囚徒 | 跟随卢平的指引，在两盏湖灯之间传递记忆之光 | 两道守护神相继驱散包围同伴的摄魂怪 |
| 第四册 · 火焰杯 | 在迷宫尽头定位三强杯，隔着树篱练习召回奖杯 | 在墓地引开追兵，夺回门钥匙，闪开封锁 |
| 第五册 · 凤凰社 | 从架上取下训练用的预言球，带到外侧通道举盾 | 漂浮咒接住预言球，铁甲咒掩护队友 |
| 第六册 · 混血王子 | 在天文塔上辨认咒结，解开阻塞楼梯的魔法 | 等火浪收拢再解咒，点射击碎残余咒痕 |
| 第七册 · 死亡圣器 | 在损毁的礼堂取回魔杖，到长桌边练习缴械 | 伏地魔三阶段决斗，依次用引诱、闪避和杖光创造缴械机会 |
| 尾声 · 霍格沃茨的黎明 | 走进修复后的礼堂，在浮动的黎明勋章下接受海格和弗立维的致意，与麦格交谈或邀请朋友重返旧副本 | 各自保留七册通关记录和黎明勋章 |

### 角色、技能与成长

| 学生 | 初始生命 / 专注 | 主动专招 | 天生特长 |
|---|---|---|---|
| 哈利 | 100 / 100 | 精准打断 | 压在敌人出手前打断，延长失衡 |
| 罗恩 | 110 / 90 | 佯攻牵制 | 接过队友身上的目标时增加牵制时间 |
| 赫敏 | 90 / 110 | 强化控物 | 举起巨怪木棒后延长伙伴的追击机会 |
| 纳威 | 105 / 95 | 草药包 | 加快救援倒地伙伴 |
| 乔治 | 95 / 105 | 响豆诱饵 | 扩大诱饵的生效范围 |

课堂可学荧光咒与漂浮咒，七册各有一门新课。玩家当前角色另有一项专招和一项自带天赋。五名学生合计有十项首阶专精选项，每名可选其一。战斗中的基础点射、引诱、闪避和扶人供全队使用。本册法术放在对应副本的第八个动作位。

每 100 经验升一级，上限 35 级。普通木偶和精英盔甲可重复挑战，每场获胜分别给 20 或 40 经验。三枚练习印记可换校徽。核心副本首次胜利给经验与技能点，七册首领各发一件专属藏品。除了为当前角色选择专精，还可投入成长点，每阶增加 6 生命或 5 专注。参与低册副本时，按该册等级范围调整战力。

### 联网与续玩

- 从「好友队伍」创建同行队伍或输入朋友给的队伍码。同一地点的朋友能看到彼此移动、跳跃和施法，在黑湖可以同船。
- 在发光入口开启独立副本，分享副本码或邀请链接。每场容纳 1–4 名不同角色的玩家，推荐三人。第一人出手后开战，队友可分工引诱、破防、输出和救援。
- 个人章节、学习记录、经验、成长与击败记录在服务器保存。换学生沿用这些进度，人物专招和专精按所选学生读取。换设备可使用私密恢复码。
- 已通关者在「好友队伍 → 副本与训练场」开旧副本或加入朋友的邀请。首胜按人结算，陪打者回到自己的章节。断线后可以重新进入未结束的副本。
- 电脑用 WASD 或方向键移动，空格起跳，Shift 奔跑，拖动镜头，E 互动，F 施法，鼠标单击点射，数字键施放战斗动作。手机使用虚拟摇杆、镜头拖动和跳跃、互动、战斗按钮。

### 开发分工与回归

| 可并行工作 | 本版交付与检查 |
|---|---|
| 选角与序章 | 五名 3D 学生、选中走位和镜头、触屏选取、实时录取信序章、跳过与自动交还控制 |
| 人物操控与 NPC | 移动、跳跃、碰撞、镜头、真实闪身、海格等人、同船、上岸恢复 |
| 关卡与任务 | 入学路线、七册空间任务、逐册课程回执、首领出口与自由活动尾声 |
| 世界与首领造型 | 七座任务地图、七座独立首领场和尾声地点，检查出生点及目标之间的通路 |
| 战斗与平衡 | 八个核心副本、两种可重复普通战斗、多人接力、单人时机、倒地、救援、团灭、重新集结 |
| 养成与奖励 | 等级、九门共享课程、五名角色专招、两选一专精、体魄与专注、独立首胜和藏品 |
| 联机与存档 | 同行邀请、副本邀请、旧存档续玩、分开过门、跨角色陪打、掉线恢复和重复结算保护 |
| 实机与发布 | 浏览器走位、选角触屏模拟、双人实战、服务器存档回归，发布到同一游戏地址 |

首版每册选取一条有起点、课程、战斗和出口的主线。人物衣橱支持六个外观部位、四种试装预设与队友外观同步。新道具接入方式见《人物换装开发说明》。逐章支线、更多阶技能和装备数值属于后续扩展。

### 本地运行

使用 Node.js 24。在本目录执行 `npm run build`、`npm start`，打开 http://127.0.0.1:4177 。本机存档位于 `.local/adventure.sqlite`。用 `npm test` 运行回归测试。
