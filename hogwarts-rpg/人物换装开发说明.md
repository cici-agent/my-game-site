# 霍格沃茨人物换装体系

游戏选角时点「打开试衣间」，或从「角色与背包」进入。独立入口为 `/wardrobe.html`。五名可玩学生各有十档练习杖、十档上衣，可以混搭。基础新生用于制作和试装。

## 接入游戏

`world/wardrobe.mjs` 定义物品、分槽规则与人物默认搭配。这份目录同时供试衣间、游戏模型和联机服务器读取。存档只记录六个物品 ID。旧数据缺少某个部位，或物品 ID 不属于对应部位时，该部位回到该人物的默认选择。

`world/player.mjs` 的 `createAvatar` 创建一个可添加到 Three.js 场景中的人物。身份特征常驻头部，躯干、头、两臂和两腿各有独立动作节点。服装在固定节点下组装，改动一个部位只替换该部位的几何体。衣装室与游戏调用同一个模型接口。

```js
import { createAvatar } from './world/player.mjs';
import { loadEquipment, saveEquipment } from './world/wardrobe.mjs';

const variant = 'hermione';
const outfit = loadEquipment(variant);
const student = createAvatar({ variant, isPlayer: true, equipment: outfit });
scene.add(student.root);

// 试戴园艺手套，保留其余五个部位。
const equipped = student.setEquipment({ gloves: 'garden' });
saveEquipment(variant, equipped);

// 在现有的游戏循环中传入秒数和角色状态。
student.animate(deltaSeconds, { moving: true, speed: 3.1 });
// 移除角色时释放其网格和材质。
student.dispose();
```

## 扩展装备

分级系列在 `world/fitted-catalog.mjs` 登记，每个款式 ID 与策划目录一致。上衣的躯干和袖子在 `world/fitted-robes.mjs` 绘制，练习杖和施法光的起点在 `world/fitted-wands.mjs` 定义。通用物品沿用下方流程。

1. 在 `world/wardrobe.mjs` 的 `ITEMS` 中找到对应部位，添加稳定的 `id`、中文 `name` 和十六进制 `color`。上衣、裤子、手套、鞋、手持物和帽子分别使用 `top`、`pants`、`gloves`、`shoes`、`weapon` 和 `hat`。手套、手持物和帽子可以卸下，各用本槽的 `none`。
2. 在 `world/avatar-outfit.mjs` 的相应绘制函数中添加造型。例如新帽子在 `headwear` 中制作，挂到 `Head`；新外套分别在 `topBody` 和 `sleeve` 中制作，跟随 `Body`、`ArmL` 和 `ArmR`。裤腰跟随躯干，两条裤腿和鞋分别跟随 `LegL`、`LegR`。
3. 新魔杖在 `handProp` 中制作，并在 `wandTips` 中指定杖尖，使施法光与新模型对齐。模型以米为尺度，Y 轴向上，人物朝向 −Z。旋转试衣镜并播放站立、行走、施法，检查脸、领口、袖口、腰线和鞋口。
4. 试衣间自动从目录列出新物品，并用真实网格生成缩略图。需要把它设为剧情角色的初始装备时，在该人物的默认搭配中填写 ID。装备与战斗数值、掉落和背包数量分别管理。

当前浏览器按人物分别保存外观。同账号的另一台设备有自己的试装记录。好友队伍和独立副本通过现有位置同步传送当前装备，队友会看到同一套装束。

## 导出模型

在游戏源码项目中运行 `node scripts/export-avatars.mjs ./models` 可从默认装束重新导出四份 GLB。每份包含命名关节、当前组合的网格，以及 `Idle`、`Walk`、`Cast` 三段动作。可替换的网格在 glTF extras 中保留 `wardrobeSlot`。运行时的完整衣柜由装备目录与绘制模块提供。

## 开源参考与取舍

**M3 Character Studio** 与这个网站最接近。它将人物模板与可选部件清单分开，清单描述部件类别、模型、缩略图和衣物遮挡。这里沿用了人物预设、部位和物品 ID 的组织方式，并保留现有 Three.js 游戏的模型与动作。该项目的代码采用 MIT 许可，素材包单独分发。[项目仓库](https://github.com/M3-org/CharacterStudio) · [部件清单示例](https://m3-org.github.io/characterstudio-docs/docs/Modders/manifest-files/overview/)

**MakeHuman / MPFB** 提供了另一种可参考的制作方法。美术可以在同一个基准人体上制作新衣，通过参考网格和权重，让衣服适应姿势。这个方法适合以后制作随膝盖、手肘变形的服装。不同来源的社区素材包各有许可。[官方服装制作教程](https://static.makehumancommunity.org/assets/creatingassets/makeclothes/introduction.html) · [素材目录与许可](https://static.makehumancommunity.org/assets/assetpacks.html)

**Three.js** 已是本站使用的三维引擎。本版用刚性关节驱动衣服和道具。今后导入带蒙皮权重的服装时，可在统一休息姿势和骨骼约定下通过 `SkinnedMesh.bind` 绑定骨架。[Three.js 蒙皮网格文档](https://threejs.org/docs/pages/SkinnedMesh.html)
