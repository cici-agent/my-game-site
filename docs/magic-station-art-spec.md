# 魔法学院星球：车站模块美术与技术规范

## 模块目标

第一阶段只完成故事开端所需的环境垂直切片：国王十字车站大厅、隐藏砖墙、九又四分之三站台、站台设施与轨道。火车、人物和远景城市分别作为后续模块制作，避免在同一轮里用低精度占位物稀释质量。

场景需要同时满足两件事：近距离看有可信的建筑、材质和陈设细节；进入浏览器后仍能在普通电脑和手机上稳定运行。

## 视觉依据与原创边界

- 官方视觉锚点：[Warner Bros. Studio Tour — Platform 9¾](https://www.wbstudiotour.co.uk/the-experience/explore-the-tour/sets/platform-9-%C2%BE/)
- 重点语言：拱形玻璃屋顶、暖黄色砖墙、深色铸铁结构、行李架、蒸汽时代站台灯、砖墙入口和纵深很强的轨道透视。
- 故事动线依据小说开端：普通车站大厅 → 寻找九、十号站台之间的入口 → 穿墙 → 看见隐藏站台 → 登车。
- 不复制或分发电影扫描模型、演员肖像或来源不明的影视资产；本项目使用原创重建、历史建筑与蒸汽铁路的通用设计语言。网站继续保留“非官方同人互动体验”说明。

## 统一坐标与尺寸

- Blender 使用米制，`1 Blender Unit = 1 米`，Z 轴向上。
- 场景原点位于隐藏砖墙入口中心的地面投影。
- Blender 的 `+Y` 是进入魔法站台的方向；导入 Three.js 后由 glTF 自动转换为 Y 轴向上。
- 网页中资产根节点放在 `(0, 0, 112)`，与现有故事的入口点对齐。
- 门洞净宽约 8 米是为了保证第三人称镜头和移动操作；它属于游戏化放大，不作为真实建筑测绘数据。

## 资产结构与命名

- Blender 源文件：`art/blender/magic_station.blend`
- 审阅图：`art/renders/magic_station_preview.png`
- 网页运行资产：`assets/3d/magic/station/platform_9_34.glb`
- 可重复生成脚本：`tools/blender/build_magic_station.py`
- 环境对象前缀：`ENV_`；道具：`PRP_`；建筑：`ARC_`；轨道：`RAIL_`；灯具：`LGT_`；标识：`SGN_`。
- 碰撞体后续使用 `COL_` 前缀并单独管理，不与可见网格混在一起。

## 材质标准

- 运行时统一使用 glTF 兼容的金属度/粗糙度 PBR 材质。
- 砖墙、石材、铁件、木材、玻璃、黄铜、搪瓷标牌和灯罩必须能从颜色、粗糙度及高光响应上区分。
- 所有外露硬边都有小倒角，避免“电脑方块”轮廓。
- 砖墙使用原创生成的可平铺颜色、粗糙度和法线纹理；不引入版权状态不明的贴图。
- 灯泡使用低强度自发光材质；实际照明由网页场景灯光统一控制。

## 浏览器性能预算

以下是首轮目标，不是最终硬性上限；每次迭代都需要用真实设备复测：

- 车站环境 GLB：目标小于 25 MB。
- 桌面端可见三角面：目标不超过 50 万；移动端后续建立低模层级，目标不超过 18 万。
- 环境材质尽量控制在 16 个以内，重复构件合批导出，减少浏览器绘制次数。
- 桌面端目标 60 FPS；普通手机最低目标 30 FPS。
- 下一轮采用 KTX2/Basis 纹理压缩和 Meshopt/Draco 中适合本项目的一种网格压缩方案，再比较画质与加载耗时。

## 本模块验收标准

1. 从大厅侧第一眼可识别为大型维多利亚式铁路车站，而不是基础几何体拼装。
2. 入口、站台、轨道与后续火车位置在同一真实尺度下，不出现人物和建筑比例失真。
3. 玻璃顶棚有连续拱形轮廓、铁肋、纵梁和承重柱；砖墙与石材有近景细节。
4. 至少包含站钟、站牌、长椅、行李架、手推车、行李箱、灯柱和轨道系统。
5. 玩家能从大厅走到砖墙，并在穿墙后无缝进入隐藏站台；原有章节逻辑不回退。
6. Chrome 桌面端完成加载、移动、穿墙和登车触发验证；手机布局不阻塞操作。
