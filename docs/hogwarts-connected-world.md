# 第一学年连续世界与旅程

本文描述当前开发候选版本与验收依据，不表示这一轮改动已经发布。

## 玩家体验

游戏把任务进度与所在地点分开。完成一个目标后，玩家留在原地，下一目标指向实际房间或道路；普通房门直接步行穿过，不再生成临时桥梁、自动走位或用任务切换整座房间。地图有世界与当前区域两种视图，世界图按同一坐标绘制并分楼层查看，地图按钮不传送人物。

伦敦国王十字站厅、九又四分之三站台和列车车厢能够连续步行。完成车内入学任务后，玩家启动约 120 秒的列车旅程；车内仍可走动、与乘客交谈，窗外景物移动。列车停稳后，经真实侧门进入霍格莫德站，沿山路到黑湖南岸。乘车计时由服务器保存，刷新或离线不会重启旅程。

海格先带路到南岸，再与玩家登船。黑湖航线约 50 米，渡湖约 70 秒；船、船桨、海格和玩家沿同一路线移动，靠岸后下船。完成入学渡湖后开放绕湖东岸道路，可从校园步行返回车站，不要求重放初次入学任务。

| 旅程 | 当前实现 | 时间与结束条件 |
| --- | --- | --- |
| 霍格沃茨特快 | 伦敦与霍格莫德各有实体站台、列车侧门和同一车厢布局；行驶时隐藏驻站环境，车内姿态与镜头不因到站重置 | 服务器记录 `120` 秒，未到站不能下车；到期后在下一次同步时完成一次到站结算 |
| 初次渡过黑湖 | 黑湖水面为 `104 × 86` 米；南岸是实体陆地和短码头，航道没有贯穿水面的长桥 | `70` 秒；船中心从湖区坐标 `(1.5, 46)` 到 `(-1.5, -4)`，航程约 `50.09` 米；随后解除乘船状态并下船 |
| 完成入学后的返站 | 沿湖面东侧的实体岸路往返，路线绕至世界坐标 `x = 58`，不横穿湖面 | 自由步行，不重复初次渡湖，也不新增该任务经验 |

## 区域结构

| 区域 | 连接与用途 |
| --- | --- |
| 国王十字站厅 → 隐藏站台 → 特快车厢 | 同一伦敦区域，步行进入列车 |
| 特快车厢 → 霍格莫德站 | 长途列车旅程；只有到站才改变所处世界 |
| 车站 → 山路 → 黑湖 → 前庭 | 初次入学跟海格渡湖，之后可沿东岸道路往返 |
| 门厅、底层长廊 | 通往大礼堂、教学庭院、校园道路及楼梯 |
| 各层长廊与折返楼梯 | 真实楼层高度；通往魔咒教室、图书馆、盥洗室、校医院及三楼禁区 |
| 地下长廊 | 魔药教室和通往底层的楼梯 |
| 格兰芬多休息室 | 壁炉、座位及画像入口，承接生活与剧情目标 |
| 厄里斯魔镜空教室 | 独立房间，保留镜子和相关剧情位置 |
| 天文塔 | 通过连续楼梯抵达，承接诺伯交接剧情 |
| 校园道路 | 温室、飞行草地与魁地奇场、海格小屋、禁林及湖岸道路 |
| 活板门地下关卡 | 路威、魔鬼网、飞钥匙、巫师棋、倒下的巨怪、药水房、魔镜密室分别有固定区域地址 |

地下活板门是单向坠落；终局获救后在医院苏醒是明确的剧情转场。它们与长途列车是保留的特殊交通，普通校园移动不使用这些方式。

## 角色与乘客

哈利、罗恩、赫敏继续使用原工坊模型、骨架与动作。列车在进入时就有常驻乘客，缺席的主角作为剧情同伴坐在车内；已由玩家或同区域队友控制的人物不生成第二份故事角色。纳威和德拉科各有座位，糖果车女巫站在推车旁，配有交谈、眨眼、视线及坐姿。车程超过 `70%` 时闲聊改用临近到站的台词；互动点靠近中央过道，不要求玩家穿过座椅。

糖果推车停靠车厢右侧，带木托盘、铜轮、纸包、糖果盒与玻璃罐。目前糖果车提供场景展示与闲聊，没有新增购买、物品结算或经验奖励。纳威和德拉科是剧情配角，不增加可选玩家角色。

## 联机与存档约定

`chapter-one/world-atlas.mjs` 是区域、门口、门禁、楼梯高度和路线查询的共同来源。每个区域具有固定世界原点；存档和移动报文始终保留区域内坐标。步行换区时，服务器验证实际门口、剧情条件和落地状态，再以两个区域的原点差转换坐标，因此玩家的世界位置不变。

区域切换递增 `locationEpoch`。旧区域尚未返回的移动报文不能覆盖新区域位置。列车、奖励与换区请求具有请求编号，重试不重复奖励，也不重启行程。每名玩家独立进入或离开区域，队伍成员不会因队长走过门而被一起传送。

旧存档按原场景和当前目标推断区域地址。旧黑湖几何调整只迁移位置与未完成护送状态，保留角色、奖励、物品和已完成任务。没有新增数据库表迁移。

## 画面与资源

当前房间及可见相邻区域提前驻留，换区复用已创建的环境。城堡室外轮廓来自实际区域位置；只有当前环境启用主灯光，列车行驶时隐藏驻站邻区。返回选角或离开驻留范围时释放环境实例和材质，三个工坊人物的原始资源不修改。

城堡走廊补齐室内天花板上方至下一楼层的外墙，南侧上层翼楼补下部立面与避开道路的高位斜撑，天文塔移除超出塔体的旧大地坪。列车侧门廊改用与车体一致的红色、奶油色门框和木地板。2026-11-22 浏览器船上机位复查确认：远处悬空层板已消失、城堡主体墙面连续，船上能同时看见玩家、海格和对岸；海格后脑的头发覆盖也已实拍复核。这是具体机位的视觉验收，不代表整章全部镜头或全部设备均已验收。

## 验收范围

自动化覆盖门口全宽通行、两侧地面、人体净空、楼梯逐帧高度、镜头与地标连续性、旧报文拒绝、列车断线恢复、独立队友区域及资源释放。测试依据对应以下源文件：

| 测试文件 | 可验证的范围 |
| --- | --- |
| `chapter-one-atlas-environment.test.mjs` | 每个步行门脚下有实际地坪、人体高度开口、楼梯与共享高度函数一致、湖面与岸路不交叉、50 米航线无桥、南岸支撑、车站围合和环境资源只释放一次 |
| `chapter-one-world-atlas.test.mjs` | 固定区域地址、门两端的世界坐标、完整门宽与双侧通行、楼层路线和剧情门禁 |
| `chapter-one-control-world.test.mjs` | 完整客户端帧循环中的跨门、镜头和地标连续性、持久车厢到站、NPC 朝向、乘船座位以及楼梯跳跃 |
| `chapter-one-online.test.mjs` | 120 秒列车计时与离线恢复、70 秒且大于 49.5 米的实际渡湖、下船后恢复移动、旧湖区存档迁移和队友独立换区 |

2026-11-22 独立重跑环境、旅程和场景细化的三个文件，共 `21` 项测试通过，包含城堡楼层外墙连续、上层翼楼下的校园道路保持净空及旧塔顶浮板移除。`journey-transition.mjs` 中的 `planJourney`、`createJourneyTransition` 和 `configureGateway` 只保留兼容测试，当前世界运行时不调用这些临时桥与过场函数；同文件的 `createTrainScenery` 仍用于车窗移动景物。实际步行换区使用持久区域地图。可在 `hogwarts-rpg/` 下复现：

```sh
node --test tests/chapter-one-atlas-environment.test.mjs tests/chapter-one-journey.test.mjs tests/chapter-one-scene-finishing.test.mjs
```

完整第一章回放包含 36 个主线目标与 127 条既有奖励事件；首领胜利的流程回放使用明确标注的可信测试结果。真实首领战与五客户端联机由独立测试覆盖，不能把流程回放或五个可见模型当作完整联机战斗验收。最终发布仍以当前提交的全量测试、浏览器实地操作和正式域名核验为准。

## 性能测量边界

当前图包含 `47` 个区域和 `102` 条有向连接。2026-11-22 对驻留环境做无相机裁剪的网格统计如下；数值包含实例数量，不包含工坊角色加载后的额外成本：

| 起始位置 | 驻留区域 | 可见环境网格批次 | 几何三角形上界 |
| --- | ---: | ---: | ---: |
| 校园 `GROUNDS` | 21 | 519 | 1,174,928 |
| 伦敦站厅 `SC01` | 3 | 246 | 579,796 |
| 一层长廊 `CORRIDOR_1` | 5 | 164 | 183,672 |

这组数字用于发现驻留规模和几何预算回归，不是实际帧率或 GPU draw call 的测量；相机裁剪会减少提交，阴影、湖面反射和角色渲染又可能增加额外通道。新建连接区另有每区少于 `35` 个网格批次、少于 `25,000` 个三角形的自动化预算。最终应记录浏览器、设备、分辨率和机位下的实际帧时间、渲染调用及显存占用；当前没有据此给出全设备帧率保证。

## 原著依据与游戏布局

区域类型与剧情关系参考原著及官方地点资料：[霍格沃茨](https://www.harrypotter.com/fact-file/locations/hogwarts)、[地下教室](https://www.harrypotter.com/fact-file/locations/the-dungeons)、[海格小屋](https://www.harrypotter.com/fact-file/locations/hagrids-hut)、[一年级新生应了解的校园](https://www.harrypotter.com/features/everything-a-first-year-should-know-about-hogwarts)。海格小屋位于校园边缘、邻近禁林；魔药教室位于地下，三楼禁区通向活板门剧情。

精确坐标、房间尺寸、楼梯路径、未在原著确定的教室楼层及路线压缩属于本游戏设计，不宣称是原著公布的建筑平面图。当前用每层 `10` 米的游戏空间组织走廊；休息室位于第三层南侧、魔镜空教室位于第二层南侧，是本版本的玩法布局，不是对原著楼层的考据结论。列车两分钟、渡湖七十秒也是游戏内节奏，并非故事世界中的真实旅行时长。
