# 学院角色制作包

## 给自己的角色接动作

已有 VRM 1.0 人物时，打开线上角色工作室的「试用自己的角色」，选择本地模型，就能切换站立、走路、跑步和施法。也可以把 standard-vrma 内的四份动作分别载入支持 VRM Animation 1.0 的工具。

使用学院学生骨架时，准备以米为单位、面朝 +Z、Y 轴向上的内嵌贴图 GLB。骨架含 Hips、Chest、Head，以及左右两侧的 Arm、Forearm、Hand、Thigh、Shin、Foot，左右分别用 L、R 后缀。每只鞋的鞋底绑定到对应脚骨。魔杖和握杖手作为人物资源一同准备。解压后在装有 Python 3 和 NumPy 的环境中运行：

```sh
python3 student_motion.py 新学生.glb 新学生-含动作.glb
```

工具根据目标腿长和鞋底重新计算站立、步行和跑步，并把抬手、绕圈、挥出和收势写成 Cast。多根魔杖的模型可在命令末尾加 `--wand-node Wand_vine` 明确校准用的魔杖。输出文件可直接在能播放 glTF 动画的工具里检查。examples 目录内的赫敏和罗恩可以直接试播。应用到游戏时使用实际移动距离驱动步频，在每次换动作时衔接姿态；进入游戏的接口见仓库 docs/magic-characters.md。

## 表情与换装

runtime 目录包含游戏使用的 Three.js 移动、表情和施法模块。走跑控制器会查找可用的眼睑、视线、嘴唇和脸颊形变，按各角色的能力加入眨眼与换气。可以在 glTF 场景 extras.expressionAliases 中登记自定义形变，例如 `{"jaw":"Part lips"}`。需要完整肌肉表演的角色，应先制作对应的眼、嘴和脸颊形变。纯骨架学生仍可使用四段身体动作。

要加入学院衣装室，在 js/magic/character-catalog.js 登记角色标识、姓名和默认魔杖，并提供其头像与模型。三套衣装的节点名为 Outfit_robe、Outfit_uniform、Outfit_travel，魔杖节点为 Wand_holly、Wand_vine、Wand_willow。长袍、特殊鞋跟和指形应按该人物检查；实际握柄应对准右手掌。

步行和跑步的动捕来源、面部基础网格与许可见 model-license.txt。VRM 文件的接入和施法关键时刻见 standard-vrma/使用说明.md。
